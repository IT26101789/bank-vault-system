# Bank Vault Security System

A C++ project developed as part of my BSc (Hons) in Cyber Security studies at SLIIT. The system models a secure bank vault with password-based access, an intrusion alarm, and motion monitoring.

## Features

- **Access control:** the vault door opens only when an authorised person enters the correct password.
- **Intrusion alert:** an incorrect password triggers a beep alarm.
- **Motion monitoring:** a sensor monitors movement around the vault.

## Technologies Used

- C++

## How to Run

1. Download or clone this repository.
2. Compile the program:
```
   g++ bank_vault_system.cpp -o bank_vault_system
```
3. Run it:
```
   ./bank_vault_system
```
